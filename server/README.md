# Project Title: NestJS Microservices CRUD API

## Description
This project is a NestJS Microservices CRUD API that connects to a MySQL database hosted on Aiven cloud. It provides endpoints for managing roles, users, employees, and attendance records.

## Installation
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the server directory:
   ```
   cd server
   ```
3. Install dependencies:
   ```
   npm install
   ```

## Configuration
- Ensure that you have a MySQL database running
- Update the database connection settings in the `.env` file as needed.

## Running the Application
To start the application in development mode, run:
```
npm run start:dev
```
